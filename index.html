What is RISC-V?

RISC-V (“risk-five”) is a free, open instruction set architecture from UC Berkeley: anyone can build a chip with it, no license fees. RISC means a small set of simple, fixed-format instructions that are easy to make fast. RV32I is the base 32-bit integer version: 32 registers (x0 is always 0), 32-bit instructions, load/store memory access, ~40 base instructions.

Instruction formats

R add/sub/and/or · I addi/lw/jalr · S sw/sb/sh · B beq/bne/blt · U lui/auipc · J jal. The Immediate Generator sign-extends the immediate for I, S, B, U and J types.

Single-Cycle vs 5-Stage Pipeline: the difference

Single-Cycle5-Stage Pipeline
ExecutionWhole instruction (fetch→writeback) in one clockSplit into IF, ID, EX, MEM, WB; 5 instructions overlap
Clock periodLong: IMEM→RegFile→ALU→DMEM→WB critical pathShort: only the slowest stage + register setup (~3× faster clock)
CPI1Ideal ≈1; higher with stalls/flushes
Hardware useUnits sit idle most of each cycleAll stages busy every cycle
Extra hardwareNoneIF/ID, ID/EX, EX/MEM, MEM/WB registers, Forwarding Unit, Hazard Unit
HazardsNoneData (forward from EX/MEM or MEM/WB), load-use (stall 1 cycle), control (flush on branch/jump)
ComplexitySimpleComplex
